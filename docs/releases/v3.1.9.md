## 新版本亮点 / What's New

以下是 **v3.1.8 → v3.1.9** 的变更。These changes cover **v3.1.8 → v3.1.9**.

- **Keenable 网页搜索 / Keenable web search** — 新增 Keenable 搜索供应商，无需 API Key 即可使用，也可选填密钥。Add the Keenable search provider, usable without an API key, with an optional key.
- **侧栏与标题栏 / Sidebar and titlebar** — 重新设计侧栏导航图标并加入悬停动效；外部 CLI 沙箱选择移到标题栏，新增 Grok 用量环；输入栏像素用量条改为无缝 6×4 大格。Redesign sidebar navigation icons with hover motion, move the external CLI sandbox picker to the titlebar, add a Grok usage ring, and render the usage strip as a seamless 6×4 grid of larger cells.
- **精简功能 / Removed features** — 移除作品库和内置专家助手；旧的作品页链接回到聊天。设置页侧栏不再提供折叠按钮。Remove the Works library and built-in expert assistants; old Works links fall back to chat. The settings sidebar no longer has a collapse toggle.
- **聊天修复 / Chat fixes** — 修复虚拟列表行高未及时测量导致的消息重叠；修正 Agent 提示词冲突，Chat 模式允许 HTML 页面工具；子代理对话不再显示默认注入的模型输入；标题摘要按普通回复以低思考强度发送；选中行上的生成中动画保持可见。Fix overlapping messages caused by stale virtual-row measurements, resolve Agent prompt conflicts and allow HTML tools in Chat, hide default-injected model input in sub-agent conversations, send title summaries like normal replies with low thinking, and keep the generating indicator visible on the selected row.
- **备份恢复 / Backup restore** — 导入错误改为可读提示；完整恢复失败可回滚，并可中途取消。Show readable import errors and make full restores recoverable and cancellable.
- **ACP 终端 / ACP terminal** — 通过登录 Shell 执行命令，合并插件 PATH 并校验工作目录；含空格的可执行文件路径可直接运行。Run commands through the login shell, merge plugin PATH, validate the working directory, and execute paths containing spaces directly.
- **安全与构建 / Security and builds** — 将 `calamine` 升级到 0.38，修复 xlsx 知识库解析在畸形文件上崩溃或耗尽内存的问题（RUSTSEC-2026-0436）；发版在线模型库不可用时回退到已校验的内置快照，并统一 Rust 格式。Upgrade `calamine` to 0.38 to fix panics and unbounded allocation on malformed spreadsheets (RUSTSEC-2026-0436), fall back to the validated bundled model catalog when the online database is unavailable during release, and normalize Rust formatting.
