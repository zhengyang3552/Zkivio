## 新版本亮点 / What's New

以下是 **v3.1.1 → v3.1.2** 的变更。These changes cover **v3.1.1 → v3.1.2**.

### 聊天与运行时 / Chat and runtime

- **中断恢复 / Interrupted responses** — 模型流中断后自动重试，显示恢复状态；丢弃失败轮次的未完成内容，保留已完成工具结果。Retry interrupted model streams with visible recovery status, discarding unfinished content while retaining completed tool results.
- **协议兼容 / Protocol compatibility** — 改进推理内容回放、多行 SSE 解析、工具调用及取消处理，完善 MCP 连接与 HTML 预览的资源清理。Improve reasoning replay, multiline SSE parsing, tool calls, and cancellation, with better MCP connection and HTML preview cleanup.
- **Goal 模式 / Goal mode** — 从 Plan 或 Orchestrate 进入 Goal 时切换到 Act，保留已有计划；修复普通生成失败被误判为限流。Switch from Plan or Orchestrate to Act when starting a goal while preserving the saved plan; stop misclassifying ordinary generation failures as rate limits.
- **工作目录与输入 / Working directories and input** — 普通聊天共用默认工作目录，保留原生会话绑定；修复输入框全选删除，并减少页面切换时的背景闪烁。Share the default working directory across ordinary chats while preserving native session bindings; fix select-all deletion and reduce background flicker during navigation.
- **定时任务 / Scheduled tasks** — 完善任务生命周期、活动运行状态与存储处理。Improve scheduled-task lifecycle, active-run state, and storage handling。

### 模型与外部 CLI / Models and external CLIs

- **推理能力 / Reasoning controls** — 按模型实际能力处理思考设置，更新 Claude Haiku 型号并保留旧标识，新增 Qwen 模型选项。Apply thinking settings according to model capabilities, update Claude Haiku identifiers while retaining older IDs, and add Qwen model options.
- **Pi 与 Antigravity / Pi and Antigravity** — 正确处理 Pi 已消费的输入及中止结果；适配 Antigravity CLI 的用量、上下文及推理能力。Handle consumed Pi input and aborted runs correctly; adapt Antigravity CLI usage, context, and reasoning capabilities.
- **浏览器连接 / Browser connection** — 保存 Playwright 扩展连接令牌，改善后续连接的连续性。Persist the Playwright extension connection token for subsequent sessions.

### 桌面与工具 / Desktop and tools

- **翻译输入 / Translation input** — 改进输入翻译、语言选择与紧凑下拉菜单。Refine input translation, language selection, and compact dropdown menus.
- **翻译浮窗 / Translator overlay** — 禁止输入翻译浮窗被双击最大化，保留拖动和随内容自动增高。Prevent double-click maximization of the input translator while retaining dragging and content-driven resizing.
- **媒体站与作品 / Media station and works** — 媒体输入区减少嵌套边框，参数使用紧凑文字下拉；作品页默认按列表排列。Reduce nested borders in the media composer, use compact text dropdowns, and open Works in list view by default.
- **macOS 窗口 / macOS windows** — 修复交通灯按钮独立移动后的位置恢复（macOS 专属，Linux 不涉及）。Restore traffic-light positions after individual window controls move (macOS-only; not applicable to Linux).
- **执行与安全边界 / Execution and security boundaries** — 加强工具执行、附件、OAuth 和协议处理边界，预编译协议校验器以适配生产环境 CSP。Harden tool execution, attachments, OAuth, and protocol boundaries; precompile protocol validators for production CSP compatibility.

### 构建与依赖 / Build and dependencies

- **ESLint flat config** — 迁移到扁平配置，并同步修正 release 类型与格式检查。Migrate to ESLint flat config and fix release-type and format checks.
- **依赖对齐 / Dependency alignment** — Rust 侧 `tauri` 升级至 2.12.4、`tauri-plugin-dialog` 至 2.8.3，npm 侧 `@tauri-apps/api` / `plugin-dialog` 同步对齐，避免版本不匹配导致构建失败。Bump `tauri` to 2.12.4 and `tauri-plugin-dialog` to 2.8.3 on the Rust side, aligned with `@tauri-apps/api` / `plugin-dialog` on the npm side.
- **Cargo.lock 同步 / Cargo.lock sync** — 重新生成 lock 以与 manifest 一致（本仓库新增 `fix-lockfile` 手动工作流，后续同步可直接一键修复）。Regenerate the lockfile to match the manifest; this fork adds a manual `fix-lockfile` workflow for future syncs.
