## 新版本亮点 / What's New

以下是 **v3.1.6 → v3.1.7** 的变更。These changes cover **v3.1.6 → v3.1.7**.

- **macOS 红黄绿按钮 / macOS window controls** — 按实际 WebView 坐标对齐原生窗口按钮，改善失焦、缩放、页面切换及标题栏延迟加载后的定位。Align native window controls with the actual WebView coordinates and restore alignment after focus changes, resizing, navigation, and delayed titlebar mounting.
- **中文输入 / IME input** — 修复输入法预编辑文字与输入框占位提示重叠。Hide the composer placeholder as soon as IME composition begins.
- **CLI 账号与额度 / CLI accounts and usage** — 主窗口和独立窗口新增 Codex、Claude Code 只读账号面板，按需显示套餐、剩余额度、重置时间与可用余额。Add an on-demand, read-only account panel for Codex and Claude Code, showing available plan, quota, reset, and credit information in both chat windows.
- **模型与服务等级 / Models and service tiers** — 完整读取 Codex 模型目录，按模型能力处理图片并标注仅文本模型；支持 Codex 模型提供的服务等级选择及会话保存。Read the complete Codex model catalog, respect image capabilities, label text-only models, and persist supported Codex service-tier choices per conversation.
- **回复与交互同步 / Response and interaction synchronization** — 修复最终正文缺失、重复或与草稿不一致；支持并行问答与审批，及时清理撤回或超时交互，避免子线程事件提前结束主对话。Reconcile final native text, handle concurrent questions and approvals, clear withdrawn or expired interactions, and isolate child-thread completion events.
- **运行中引导与恢复 / Steering and recovery** — 改善 Claude 运行中指令的送达确认与前台子 Agent 协调；修正中断和失败判定、慢速切模确认及模型探测日志阻塞，保留续聊附件路径。Improve Claude steering receipts and foreground-agent coordination, correct cancellation and failure handling, tolerate slower model-switch acknowledgements, drain model-probe logs, and retain attachment paths in resumed turns.
- **Git 初始化保护 / Git initialization safeguards** — 初始化仓库前要求选择项目，并使用所选项目的实际路径，避免误在共享根目录初始化。Require a selected project and resolve its actual directory before initializing a repository to avoid initializing the shared root.
