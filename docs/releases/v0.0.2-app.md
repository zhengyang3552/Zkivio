# Kivio Android v0.0.2

手机上的 AI 助手，带一个真正能跑命令的 Linux 工作区。An AI assistant on your phone with a real Linux workspace.

## 下载 / Downloads

- **正式版 APK / Release APK** — `kivio-0.0.2-arm64-release.apk`（arm64-v8a，24.5 MB，release 构建 / release build）
  - 自签名，安装时需允许「安装未知来源应用」；后续版本同签名，可直接覆盖升级。Self-signed; allow installs from unknown sources. Later builds share the same key and upgrade in place.
  - 首次启动后请到系统设置给 Kivio 授予「所有文件访问」，否则工作区无法解压 rootfs、无法读写文件。Grant "All files access" after first launch, otherwise the workspace cannot unpack its rootfs.
- **校验 / Checksum** — `SHA256SUMS.txt` 随包提供。Provided alongside the APK.

## 新版本亮点 / What's New

首个公开的安卓版本。First public Android release.

- **手机里跑完整 Linux 工作区 / Full Linux workspace on device** — proot + rootfs 直接在 App 内运行，AI 可以执行 shell 命令、装包、跑脚本，技能目录与桌面端同一套结构。Runs a proot-based Linux rootfs inside the app so the assistant can execute shell commands, install packages, and run scripts, with the same skill layout as desktop.
- **可选发行版 / Selectable distro** — 工作区可建为 Alpine 或 Ubuntu 24.04，随时重建，互不影响。Create the workspace as Alpine or Ubuntu 24.04 and rebuild it at will.
- **文件区与 rootfs 分离 / Separate file area** — 用户文件放在 `/workspace`，与 rootfs 分开，重装 rootfs 不丢数据。User files live in `/workspace`, separate from the rootfs, so rebuilding the rootfs keeps your data.
- **工作区对第三方文件管理器可见 / SAF exposure** — 通过 DocumentsProvider 把工作区暴露给 MT 管理器、系统文件管理器等，可直接浏览和编辑。The workspace is exposed through a DocumentsProvider so MT Manager and system file managers can browse and edit it directly.
- **移动端交互适配 / Mobile UX** — 消息长按菜单、token 用量常显、软键盘跟随输入框、满屏去圆角、360px 窄屏页头不再挤成竖排。Message long-press menu, always-visible token usage, keyboard-aware layout, rounded-corner removal, and 360px header fixes.
- **目录选择走系统选择器 / System folder picker** — 导入技能文件夹、设置工作目录改用 `ACTION_OPEN_DOCUMENT_TREE`，不再受应用沙箱限制。Folder import and workspace selection now use the system picker instead of app-sandbox paths.

## 已知限制 / Known limitations

- 仅 **arm64-v8a**，没有 armeabi-v7a / x86_64 包。arm64-v8a only.
- 桌面端这些能力不参与安卓编译：托盘、全局热键、单实例、开机自启、多窗口、Dock 终端、Lens 浮层、离线 RapidOCR。Desktop-only features (tray, global hotkeys, single instance, autostart, multi-window, Dock terminal, Lens overlay, offline RapidOCR) are not built for Android.
- 版本线独立：安卓走 `0.0.x`，与桌面端 `3.1.x` 不互通。Android uses its own `0.0.x` version line.
- 签名密钥随仓库公开，仅适合个人分发；上架商店前会换成独立正式签名。The signing key is public in the repo — fine for personal distribution, will be replaced with a private key before any store release.
