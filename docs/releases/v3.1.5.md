## 新版本亮点 / What's New

以下是 **v3.1.4 → v3.1.5** 的变更。These changes cover **v3.1.4 → v3.1.5**.

- **按需启用 Study / Optional Study extension** — Kivio Study 独立为扩展包，默认关闭，在插件市场的“扩展”分类中启用和打开；关闭前保存编辑，保留已有资料，并停止相关后台服务。Extract Kivio Study into a bundled extension, disabled by default and available in the marketplace’s Extensions category. Disabling saves pending edits, retains existing data, and stops extension services.
- **扩展 SDK / Extension SDK** — 仓库新增独立扩展目录、版本化公共接口与双向生命周期 Hook，为后续源码扩展提供统一接入方式。Add a dedicated extension directory, versioned public interfaces, and bidirectional lifecycle hooks for bundled source extensions.
- **论文与教材阅读 / Reading papers and textbooks** — 新增文献库、文献集和 PDF 阅读工作区，支持页面图像问答、选区与批注关联 AI，并改善中文 PDF、搜索、面板布局和加载性能。Add a literature library, collections, and PDF reading workspace with page-image questions, selection and annotation context for AI, plus improvements to Chinese PDFs, search, panel layouts, and loading performance.
- **保存与历史修复 / Saving and history fixes** — 改善笔记、草稿和附件保存，保护跨窗口编辑；自动清理已删除聊天的失效关联，避免反复打开报错，并保留笔记与草稿。Improve note, draft, and attachment persistence and protect multi-window edits. Remove confirmed stale links to deleted conversations while retaining notes and drafts.
- **学习与写作工具 / Study and writing tools** — 提供可选 PDF 翻译组件、译文阅读、文献子项、引用管理与 Word 本机连接；可按需配置，不影响基础阅读。Add optional PDF translation setup, translated-document reading, literature child items, citation management, and a local Word connection alongside basic reading.
- **工具连续执行 / Continuous tool execution** — 移除工具轮次上限及对应配置，修复长任务因达到轮次限制而提前结束的问题。Remove tool-round limits and related settings so long tool-driven tasks can continue without ending at a round cap.
- **DeepSeek 搜索 / DeepSeek search** — 接入原生 Search 与 Fetch 接口，改善搜索结果、来源及网关地址兼容性。Adopt native Search and Fetch APIs and improve result, source, and gateway URL handling.
- **桌面体验与安全 / Desktop experience and security** — 改善 Momo 动效与交互文案，修复桌面对话框权限；更新 ZIP、证书校验及根证书依赖，解决相关安全公告。Improve Momo motion and interaction copy, fix desktop dialog permissions, and update ZIP, certificate verification, and root-certificate dependencies to resolve security advisories.
