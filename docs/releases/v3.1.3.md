## 新版本亮点 / What's New

以下是 **v3.1.2 → v3.1.3** 的变更。These changes cover **v3.1.2 → v3.1.3**.

### 聊天与运行效率 / Chat and performance

- **技能按对话加载 / Conversation-scoped skills** — 技能、插件角色和 Hook 在对话初始化时扫描，后续复用；使用 `/reload` 刷新。技能正文按需读取，发现技能时不再遍历全部资源文件。Discover skills, plugin roles, and hooks once per conversation and reuse them until `/reload`; read skill instructions on demand without walking every resource file during discovery.
- **外部 CLI 技能 / Skills for external CLIs** — Kivio 附加技能的资源副本按对话隔离并复用，正文变化或重载后刷新，失败保留旧副本；CLI 原生命令仍由 CLI 处理。Isolate and reuse copies of Kivio-attached skill resources per conversation, refresh after instruction changes or reloads, and retain the previous copy on failure while preserving native CLI commands.
- **子代理与列表性能 / Subagents and list performance** — 子代理进度不再反复重写完整历史；减少费用统计、笔记列表和自动化检查点的重复磁盘读取，合并 Git 面板刷新并隔离迟到结果。Avoid rewriting full subagent histories for progress updates, reduce repeated disk reads for costs, notes, and automation checkpoints, and coalesce Git refreshes while rejecting stale results.
- **上下文与重试 / Context and retries** — 上下文过长时进行有界压缩恢复，失败保留原记录；统一请求重试并显示倒计时，修正外部 CLI 的上下文用量统计。Recover from oversized context with bounded compaction while preserving original records on failure; unify request retries with countdowns and correct external CLI context usage reporting.

### 数据与模型 / Data and models

- **备份与恢复 / Backup and restore** — 新增配置导出与完整 `.kivio` 备份；完整恢复先校验、重启后应用并保留恢复前副本，项目文件恢复到独立目录，避免覆盖本机已有项目。Add configuration exports and full `.kivio` backups; validate full restores before applying them on restart, retain pre-restore data, and restore project files into a separate directory to avoid overwriting existing projects.
- **模型库更新 / Model catalog updates** — 支持手动更新模型资料并保留用户配置；发布构建自动使用同一份模型库快照。Update model metadata manually while preserving user configuration, and bundle the same model catalog snapshot in release builds.

### 桌面与兼容性 / Desktop and compatibility

- **翻译语言 / Translation languages** — 阅读翻译与输入翻译可分别设置目标语言，并新增 18 种目标语言。Configure separate target languages for reading and input translation, with 18 additional language options.
- **电脑控制与设置 / Computer control and settings** — 电脑控制改用 Skill 与 CLI，保留安装和更新入口；移除旧连接器设置页，并在侧栏提示可用的新版本。Use a Skill and CLI for computer control with installation and update controls; remove the legacy connectors settings page and show available app updates in the sidebar.
- **显示与兼容修复 / Rendering and compatibility fixes** — 修正金额文本被误识别为数学公式、ClawHub 访问受阻等问题，整理 Agent 提示词，更新 rustls。Fix currency text being mistaken for math and blocked ClawHub access, refine agent instructions, and update rustls.
