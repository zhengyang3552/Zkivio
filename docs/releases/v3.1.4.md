## 新版本亮点 / What's New

以下是 **v3.1.3 → v3.1.4** 的变更。These changes cover **v3.1.3 → v3.1.4**.

- **WebDAV 备份 / WebDAV backups** — 新增手动上传配置或完整备份、查看远程备份、恢复和删除；提供连接测试与服务配置提示，并改善目录、文件列表及错误处理兼容性。Add manual configuration and full backups over WebDAV, with remote listing, restore, deletion, connection testing, service setup guidance, and improved compatibility handling.
- **运行中补充消息 / Messages during a running turn** — 优先将新消息直接交给当前运行处理；不支持或未受理时保留到轮末发送，并修正输入框及消息展示状态。Prefer delivering new messages to the active run, retain unsupported or rejected messages for follow-up, and correct composer and message presentation states.
- **停止回复 / Stopping responses** — 停止时保留已经生成的内容，减少额外停止提示，并修正流式预览与历史显示。Preserve generated content when stopping, reduce redundant stop notices, and correct streaming previews and history rendering.
- **加载响应 / Loading responsiveness** — 将多处文件读取、解析和扫描移出 UI 线程，改善笔记、技能、插件、知识库及用量页面的加载响应。Move file reads, parsing, and scans off the UI thread across notes, skills, plugins, knowledge bases, and usage views.
- **模型与兼容修复 / Model and compatibility fixes** — 更新模型价格与推理档位资料，修复桌面端 MCP 注册表请求限制，并调整深色侧栏、加载背景与按钮悬停样式。Update model pricing and reasoning metadata, allow desktop MCP registry requests, and refine dark sidebar materials, loading backgrounds, and button hover styles.
