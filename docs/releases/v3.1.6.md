## 新版本亮点 / What's New

以下是 **v3.1.5 → v3.1.6** 的变更。These changes cover **v3.1.5 → v3.1.6**.

- **输入与笔记 / Composer and notes** — 修复输入法组合期间草稿同步打断编辑、选字后首次发送回车被忽略的问题；修正浅色主题下笔记代码块行号的深色背景，并统一光标与当前行配色。Defer draft synchronization during IME composition, handle the first send Enter after character confirmation, and align note code-block gutters, carets, and active lines with the app theme.
- **聊天阅读位置 / Chat reading position** — 改善历史阅读时的位置保持，修复流式回复结束、消息回退或删除后的留白与滚动跳动。Preserve the reading position in chat history and correct reserved whitespace and scrolling after streaming, rewinds, and message deletion.
- **缓存与费用统计 / Caching and usage costs** — 稳定请求缓存前缀，减少动态运行上下文造成的缓存失效；缓存命中率计入写入量，Claude 缓存写入费用区分短期与长期。Stabilize request prefixes to reduce cache invalidation from changing runtime context, include cache writes in hit-rate accounting, and distinguish short- and long-lived Claude cache-write costs.
- **请求错误与截断恢复 / Request errors and truncation recovery** — 区分永久输入错误与临时故障，避免无效重试，校验异常图片并保留已完成的工具结果；对符合条件的异常截断回答压缩上下文后重试一次。Distinguish permanent input errors from transient failures, avoid futile retries, validate images, retain completed tool results, and retry eligible truncated responses once after context compaction.
- **图片上下文 / Image context** — 改善上下文压缩时的图片保留策略，在字节预算内保留重新读取的图片。Improve image retention during compaction and preserve reread images within the byte budget.
- **macOS 窗口 / macOS windows** — 修复窗口失焦后原生红黄绿按钮的位置错乱。Correct native window-control positioning when a window loses focus.
- **插件与设置调整 / Plugin and settings changes** — 移除 OfficeCLI 集成，精简 Hooks 设置的事件列表、配置示例和工作流区块；加深图片加载占位背景，并调整 Git 状态图标。Retire the OfficeCLI integration, simplify Hooks settings, darken image-loading placeholders, and adjust the Git status icon.
- **独立开发版 / Isolated development app** — 新增 Kivio Dev 独立身份，隔离正式版的应用数据、用户技能、OAuth 凭据及相关本机服务；开发版默认关闭自动更新、启动项和全局快捷键。Add a separate Kivio Dev identity with isolated app data, user skills, OAuth credentials, and related local services; disable automatic updates, launch at startup, and global hotkeys by default in Dev.
- **构建稳定性 / Build reliability** — 修复 macOS Rust 测试重复嵌入应用信息导致的编译错误，并修正预览服务端口释放测试的异步时序。Fix duplicate application-metadata embedding in macOS Rust tests and account for asynchronous preview-port release in lifecycle tests.
